## 下载与安装

- **Windows x64**：下载 `lexiday-windows-x64.exe`，便携版双击运行，无需安装。当前未进行代码签名。
- **Android 7.0 及以上**：下载 `lexiday-android.apk`，允许浏览器安装此应用后打开。当前为测试签名 APK，尚未配置正式发布签名；不同构建的签名可能不同，覆盖安装失败时先导出学习记录，再卸载旧版安装并导入记录。
- **网页版**：https://jimmy-xuzimo.github.io/ciyu-vocab/app/
- `SHA256SUMS.txt` 包含两个安装包的 SHA-256 校验值。安装包由本标签对应的 GitHub Actions 构建生成。

学习记录保存在当前设备，不会自动跨设备同步；可在设置中导出、导入。更新或卸载前建议导出记录。

当前已通过自动化测试和构建验证，尚未完成所有 Windows / Android 实机兼容性测试。
